## Other requirements and deliverables

- Source and modular systems: Godot 4.7 stable, typed GDScript, separate hero/enemy/projectile/coin actors, building actor, run controller, data, UI and visuals. The reference's proposed hierarchy is guidance, not a requirement for extra managers.
- Data: hero balance/XP/ability values, enemy stats/rewards, building costs/tiers/limits/production, Smith effects and pricing, wave timing/rosters, bounds/routes/plots/spawns/Keep are configured in `game/game_data.gd`. Hero death and advanced targeting remain explicitly deferred by the reference.
- Mobile direction: portrait, angled simple 3D, native simultaneous touch controls and responsive layout. Windows tests cover synthetic touch delivery and interruptions; physical iPhone feel/performance remains a later verification task.
- Original content: procedural meshes and synthesized sounds are authored in this project. No Kingshot assets, logos or map copies are bundled.
- Delivery: `play_windows.cmd`, `tools/run_windows.ps1`, `tools/run_macos.sh`, pinned `.godot-version`, README controls/setup, non-secret iOS preset and `docs/mac_iphone_handoff.md`. Source archive is produced by `tools/package_source.ps1`.
- Repository preparation: source uses relative paths; `.gitignore` excludes generated caches/builds/logs and signing material; `.gitattributes` normalizes text. There are no large binary assets requiring Git LFS. GitHub publication is still a later user-directed step.
- Exact commercial comparison, human play feedback, Mac/iPhone import/export/signing/performance, campaign, saves, expanded content and store release remain on the roadmap. These are not claimed complete by accepting the first playable.

## Reproduce

`powershell -NoProfile -ExecutionPolicy Bypass -File tools/validate.ps1 -Capture`

The wrapper rejects script errors, failed checks and reported object leaks, and requires success markers. It produces logs and rendered screenshots in ignored `artifacts/`. The source package must also import and pass the headless checks after fresh extraction to another directory.
