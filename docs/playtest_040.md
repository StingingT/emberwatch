# Emberwatch 0.4.0: Combat & Visual Identity playtest

This is an Android debug test build, not a production release. Start a new defense: old active checkpoints may be incompatible with the changed combat data. Campaign results and settings retain their existing profile format.

## Play the first three missions

Play Briarwood, Amberfield and Stonegate without a strategy walkthrough. Move with the stick; the hero shoots automatically. Hero damage earns XP even if towers finish enemies. Each level offers Multishot, Volley or Piercing while the battle pauses. The hero can die and returns after eight seconds while the defense continues.

Amberfield introduces wolf-pelt hunters and crossbow goblins. Dodge marked melee strikes and move after crossbow shots launch. Lead hunters into tower fire. The three floating Smith bulbs improve towers or defenses; purchases remain live during combat.

## Send back these observations

- Phone model and Android version; any crashes, slowdowns or heat.
- Which mission/wave you reached, wins/losses and approximate session length.
- Were incoming attacks readable, and did deaths feel fair?
- Which level choices did you take? Did they change how you played?
- Could you distinguish building levels without reading labels?
- Could you move and purchase from Smith bulbs comfortably?
- Did coins, kills and construction feel satisfying without hiding enemies?
- Any confusing moments or long waits. A short screen recording is useful if convenient.

## Installation

Send the APK to the tester. On their Android phone, open it and allow installation from that file app if prompted, then install Emberwatch. A matching earlier debug installation should update in place. If Android reports a signing conflict, report the message before uninstalling, since uninstalling removes local progress.

## Acceptance status

Desktop rendering and automated checks do not prove native touch behavior, performance, heat, lifecycle behavior or player enjoyment. Human playtest and reassessment remain required before resuming held features.
